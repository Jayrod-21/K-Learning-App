## Verified-clean (worth recording)

- `withTransaction` commit/rollback/release ordering is correct; no connection leak on error (modulo #5's destroy-vs-return nuance). `clientQuerier` correctly threads a tx-bound client.
- `fsrs.ts` / `grammarScheduler.ts`: clamps are NaN-safe and bounded; `STABILITY_MAX` genuinely prevents `NUMERIC(10,4)` overflow (36,500 × 3 ≪ 999,999.9999); no state can violate the 001 CHECKs.
- `diagnostic/cat.ts` + `diagnostic/scoring.ts`: θ and estimates are clamped/rounded to fit `NUMERIC(3,2)`; `estimateToScore` anchors are monotone; Agresti-Coull band math is sound. The `/answer` route's FOR-UPDATE + `answered_at IS NULL` single-shot gate correctly closes the double-answer race.
- `retry.ts`: classification is conservative, auth short-circuits, jitter is full-jitter, secrets redacted off the cause. Retrying `messages.create` is idempotent upstream (cost-only duplication).
- `kiwi.ts`: timeout-bounded, Zod-validated, single retry on transient only. (Nit: 5xx-exhaustion throws "kiwi unreachable", mislabeling a live-but-erroring upstream.)
- `topik/passages.ts` `sharedPassageFor` is total over hostile JSONB (skips malformed keys/values, no throw).
- `imageStore.ts` traversal guards are correct on both write and read paths.
- Migration 004's cache/usage constraints match the writers (`ck_claude_usage_cache_hit_zero_cost` is pre-enforced in `usage.ts:185-190`); `claude_route` enum is complete after 031/032 and pinned by a compile-time exhaustiveness check + runtime enum test.
- `migrate.py`: per-migration tx + same-tx bookkeeping, checksum drift detection, tx-control rejection in bodies — all sound. (Nit: `--target` compares versions as strings; `--target 31` matches nothing sanely — zero-pad or int-compare.)
