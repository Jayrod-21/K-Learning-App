# SWEEP — Client Services ↔ Server Contract Integrity

Adversarial bug-hunt over `client/src/services/*.ts`, `client/src/lib/*`,
`client/src/types/domain.ts`, and the wire contract between each client call and
its server route. The client's axios wrapper (`client/src/services/api.ts`)
returns the raw JSON body typed as `T` with **no runtime validation** — so every
field-name / shape / type diff between a service's declared `T` and the server's
actual response is a silent `undefined` (or wrong-typed value) at runtime, never
a caught error. That is the failure class hunted here.

Traced BOTH sides for every finding (client field/read ↔ server route → service
→ SQL column). Skipped per scope: F-UP-013/014/015/016/017, B-012.

Severity counts: **3 HIGH · 5 MED · 8 LOW.** Most-severe first.
