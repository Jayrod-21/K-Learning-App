## Verified-clean (no defect found)

- **Answer keys in range**: 0 items with a numeric `answer` outside `1..len(options)` when options exist; 0 MC items with NULL answer; 0 duplicate/empty/non-string option texts among served items.
- **Hangul normalization**: 0 NFD-contaminated rows across `topik_items.stem`, `krdict_entries.headword`, `vocab_entries.korean`, `kgiu_entries.pattern`, `iyagi_sentences.korean`, `canonical_grammar.canonical_pattern`.
- **vocab-2000 (B-012 spot-check)**: loader faithful — 1,598 + 1,590 word rows; source-id numbering gaps exactly equal the non-word (navigational) rows (101/97); duplicate `korean` values are genuine homonyms (말, 배, 등). 1 empty-english row is `user_mined`, not corpus.
- **KRDICT**: 0 entries without senses, 0 senses without definitions, 0 empty headwords (53,978 entries / 634,600 examples intact).
- **TTMIK/Iyagi**: every non-NULL `audio_path` (232 lessons + 139 episodes sampled in full) resolves to a file under `~/data/korean-master/corpus/`; 0 lessons with neither sentences nor transcript lines; 0 episodes without sentences. `iyagi_sentences.english` is NULL for all 11,162 rows **by design** (parser emits `english: None`; column nullable; route serves Korean-only).
- **load_state**: all 74 sources `complete`, no `failed` rows.
- **Loader duplicate/drop protection**: both `load_topik.py` and `load_vocab_2000.py` carry post-load count assertions (ADR-019 D8) that fail loud on collapse/drop; resume filtering compares zero-padded ids so lexicographic `>` is safe.
