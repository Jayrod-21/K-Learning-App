## Notes (not defects, observed while tracing)
- Several older pages echo `ApiError.message` (server-originated text) into `ErrorCard`/inline alerts (`Reference.tsx`, `Ttmik.tsx`, `Progress.tsx:214`, `Diagnostic.tsx:192`, `Topik.tsx:421`), contradicting ErrorCard's own "never echo untrusted server text" contract. React escaping makes it XSS-safe; contract drift only.
- `Review.tsx` AllPanel `MaturityBar level={(i % 4) + 1}` and ListDetailSheet preview render **fabricated** maturity derived from row index — display placeholder presented as data (Pass-2 leftover).
- `AudioBlock.tsx:69-71` calls `setPlaying(false)` inside a `setProgress` updater (updater impurity; idempotent, no visible failure).
- `RecoveryCodesPanel.tsx:72-88` — comment claims the copy timer can't "fire setState after unmount", but there is no unmount cleanup (no `useEffect` in the file). React 18 no-ops the late set; harmless today.
- Hooks (`AuthProvider`, `useEndpointOrMock`, `useModalA11y`, `SettingsProvider`, `ThemeProvider`, `ToastProvider`) traced end-to-end: abort/race handling is correct; no leaks found.
