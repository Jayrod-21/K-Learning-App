- **Judgment calls a re-reviewer should scrutinize:**
  1. *Tabs SF-2 via comment, not test* — driven by measurement (light+mint 2.99:1 fails the assertion the comment claimed); adding the test would have shipped a red suite for a token-design issue outside this pass. The corrected comment now documents that exact number.
  2. *`remaining` semantics* — next-batch count (`min(step, headroom)`) per the fix brief, not the reviewer's total-reachable (`limit - visibleCount`). Both kill the 35-vs-15 over-promise; next-batch is the strictly honest per-click number. Divergence from the reviewer's letter is deliberate and documented at `usePagination.ts:36-43`.
  3. *BackButton guard* — `location.key === 'default'` rather than `window.history.state?.idx`: the idx approach is data-router-only and unobservable under MemoryRouter (tests would exercise a different code path than production). The `"default"` key sentinel is set by the same react-router history layer in both environments; verified against the installed v7.13.1 dist.
- **Risk:** low. No public API was narrowed (Tabs `tabs` widened to ReadonlyArray; `fallbackTo` and `remaining` are additive); no consumer exists yet for Tabs/FilterSelect/usePagination/ShowMore; BackButton and the rem conversions render identically at the default md root.
- **Not done, on purpose:** the 256-declaration app-wide px→rem migration (F-086, filed), the smaller-default half of F-025 (pre-existing decision, now recorded in the ticket), and anything touching SwipeCarousel source.
