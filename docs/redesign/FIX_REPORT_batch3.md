All six pairings clear 3:1; five of six clear the stricter 4.5:1 text floor too (not required here — these are non-text border indicators, per the shared `HanjaCell`'s own accessible-name-carries-the-state design, unchanged and confirmed still true).

**One deliberate deviation from the BLOCKER's literal wording, flagged for transparency:** B1 said to use "the gray the shared default used before the override" — that default is `--paper-faint`. Measured: `--paper-faint` only clears **2.02:1 Day** / 3.18:1 Night against `--ink-1` — i.e., the literal pre-override default itself fails the 3:1 floor in Day, an inherited gap this batch didn't create but also shouldn't reproduce given the task's explicit "verify AA numerically... all three bands... in both themes" gate. `--paper-mute` was chosen instead: still a genuinely neutral gray (not red, not a skill/accent hue), already used inside `HanjaCell` itself for the caption/gloss text, and the only neutral candidate on hand that clears 3:1 in **both** themes (checked `--line-strong` too: only 1.74:1 Day — worse, it's a hairline-weight token, wrong category for a 3:1 indicator).
